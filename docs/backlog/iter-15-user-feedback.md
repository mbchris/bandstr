# Iteration 15 - User Feedback

**Goal:** Feedback from first users is considered.

## Acceptance criteria

- [x] Changing the `Bierwart` restores the confirmation dialog
- [x] On `Home`, users can immediately confirm attendance or mark absence for the next rehearsal
- [x] Marking an absence creates an `unavailability` calendar entry automatically
- [x] Attendance and absence can be reset by users
- [x] `Dashboard` is renamed to `Settings` (`Einstellungen`)
- [x] Users can add songs to their personal `User Setlist` visible only to themselves
- [x] Personal notes and global notes per song use bigger markdown-capable input fields
- [x] `Home` has a collapsible widget (collapsed by default) listing personal notes and linked songs
