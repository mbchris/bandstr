# Iteration 14 - Support page

**Goal:** Users can interact with development and submit bug reports/comments.

## Acceptance criteria

- [x] Menu item `Support` exists between `Subscriptions` and `Impress`
- [x] User can choose `Report a bug`, `Suggest a feature`, or `Leave a comment`
- [x] GitHub issues are created in configured GitHub repository
- [x] Types are preselected
- [x] Tags are set based on selected type
- [x] Backend handles connection to GitHub
- [x] User can leave message, optional screenshot, optional email
- [x] Build ID and environment are included automatically
